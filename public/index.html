Est. Pick Order = Avg. Pick % × (N − 1) + 1 · Est. Rank Order = Avg. Rank % × (N⁄4 − 1) + 1 (N⁄4 = number of teams, since each team gets 4 picks)

Difference between average performance for a given pick order and actual placement. A higher value means the player, on average, has a higher placement than the average person in their placement.

Originally tier-grouped (picks bucketed by round), simplified to a single pooled z-score after confirming every tier draws from an identical distribution of outcomes in this snake-draft format — each captain picks exactly once per round, and placement is the captain/team's outcome, identical across all of that captain's picks regardless of round. Z-score = (overall average placement − actual placement) / overall std. dev., averaged across appearances. No risk-aversion or recency weighting applied here either.
